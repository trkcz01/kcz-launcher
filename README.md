# KÇZ Launcher

Minecraft Java Edition için launcher.

**İndir:** [Releases](../../releases/latest) bölümündeki `KCZ-Launcher_..._x64-setup.exe` dosyası.
Kurduktan sonra güncellemeler launcher'ın içinden gelir (sol üstte "Güncelle").

Bu depo sadece kurulum dosyalarını ve güncellemeleri barındırır.
